Backend Integration & Architecture Guide

Project: Dispatch Planning ERP (Frontend UI)

Framework: React 19, TypeScript, Vite

Backend Developer Note: This frontend is fully functional using a local "Mock Database" (localStorage). Your primary job is to replace the synchronous `localStorage` logic with asynchronous API calls (e.g., `fetch` or `axios`). You do not need to rewrite or touch the UI components.

1. Complete File Directory & Purpose

Below is the exact breakdown of every file in the src/ directory so you understand the flow of data.

File / Folder path What it does (Purpose)
src/main.tsx Application entry point. Renders the React DOM.
src/App.tsx Custom Hash-based Router. Controls which page component is displayed based on the URL.
src/types/index.ts CRITICAL: Contains all Data Models (TypeScript Interfaces). Backend JSON responses MUST match these exact keys (or be mapped to them).
src/services/api.ts THE INTEGRATION POINT: This is a singleton Pub/Sub service layer. The entire UI reads and writes data through this single file. Backend APIs will be called from here.
src/layouts/AppLayout.tsx The main shell (Sidebar + Navbar). Also holds global Modals (like Create Dispatch) so they can be opened from anywhere.

Page Components (Screens)

File Purpose

pages/PendingPIPage.tsx "Proforma Invoices & Orders Registry". Displays all orders. Uses tabs (ALL, PENDING, APPROVED). Approvals happen here.
pages/TodaysPlanningPage.tsx Live operations execution. Moves a Dispatch through stages: Ready -> Loading -> Gate Pass -> Transit -> Delivered.

3. How to Integrate the APIs (Action Plan)

All integrations happen inside src/services/api.ts.

Step 1: Convert Synchronous getters to Asynchronous

Currently, the UI asks for data instantly. When you connect APIs, fetching takes time. You will need to fetch data on load and store it in the api.ts class properties.

// Inside DispatchDataService (api.ts)

// 1. Fetch data from backend
public async initializeData() {
    const res = await fetch('https://api.yourbackend.com/v1/orders');
    this.pis = await res.json();
    this.notifySubscribers(); // Tells React UI to re-render
}

// 2. Keep the synchronous getter for the UI
public getApprovedPIs(): ProformaInvoice[] {
    return this.pis.filter((pi) => pi.status === 'APPROVED');
}

Step 2: Connect Mutations (POST / PUT)

When the user clicks "Approve", the UI calls dispatchService.updatePIStatus(). Update this function to hit your backend.

public async updatePIStatus(id: string, newStatus: PIStatus) {
    // 1. Call Backend
    await fetch(`https://api.yourbackend.com/v1/orders/${id}/status`, {
        method: 'PUT',
        body: JSON.stringify({ status: newStatus })
    });

    // 2. Update local state
    const pi = this.pis.find(p => p.id === id);
    if (pi) pi.status = newStatus;

    // 3. Update UI instantly
    this.notifySubscribers(); 
}
Golden Rule: Whenever you change data via an API call, you MUST call this.notifySubscribers() at the end. This is what makes the Frontend UI update automatically without reloading the page.
